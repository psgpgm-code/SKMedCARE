மருந்து & சாப்பிடும் நேரம்

மருந்தின் அளவு, உணவுக்கு முன்/பின் மற்றும் நேரங்களை மருத்துவர் பரிந்துரை / prescription படி மட்டும் பதிவு செய்யவும்.

தேர்வு செய்த நேரங்களுக்கான Notification time-ஐ prescription-க்கு ஏற்ப அமைக்கவும்.

ஒரு மருந்தை நிரப்பியதும் “இன்னொரு மருந்து” அழுத்தவும். Customer தேர்வு மாறாமல் இருக்கும்; ஒவ்வொரு மருந்துக்கும் நேரம்/உணவு விவரங்களை தனித்தனியாக பதிவு செய்யலாம்.

Admin App Backup Import

SKMedKART Admin app-இல் இருந்து எடுத்த JSON Backup-ஐத் தேர்வு செய்யவும். Customer பெயர்/மொபைல், bills-ல் உள்ள மருந்துப் பெயர்கள், reminders ஆகியவற்றை மட்டும் இந்த தனி app-க்கு நகலெடுக்கும். Original backup / Admin app மாற்றப்படாது.
